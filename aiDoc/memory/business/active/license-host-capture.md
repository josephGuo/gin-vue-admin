# 非本机 Host 触发授权探测请求

## 基本信息

- 提出日期：2026-08-02
- 当前状态：`active`
- 需求类型：后端中间件
- 优先级：普通
- 需求文件：`aiDoc/memory/business/active/license-host-capture.md`

## 用户原始意图摘要

新增独立包捕获请求 Host；当 Host 不是 `127.0.0.1` 或 `localhost` 时，请求一次官方 `lock.svg` 地址。

## 影响范围

- 后端：新增全局 Host 捕获中间件并接入总路由
- 前端：无
- 文档：记录需求与 TDD 验证证据
- 插件 / 模块：无

## 涉及对象

- 模块：`server/middleware/hostcapture`
- 接口：所有进入主 Gin Engine 的请求
- 页面：无
- 配置：无，目标地址为需求指定的固定官方地址

## 已确认约束

- 本机 Host `localhost`、`127.0.0.1` 及其带端口形式不触发请求
- 第一个非本机 Host 仅触发一次，后续请求不重复触发
- 外部请求异步执行，失败不阻塞也不改变原业务响应
- 只读取标准 `Request.Host`，不信任可由代理或客户端任意注入的 `X-Forwarded-Host`
- 不向固定目标额外附加业务数据或任意 Host 参数
